# RipoN — IN IMAGINATION

Personal portfolio and digital hub of **RipoN Sahaji** — Blogger, YouTuber, and Full-Stack Developer.

Live Site: [https://ripon.in](https://ripon.in)

## Overview

- **Aesthetic**: Deep cosmic space odyssey with interactive sector stages
- **Engine**: Three.js WebGL particle field & modern vanilla ES modules
- **Typography**: 100% self-hosted local WOFF2 (`Outfit` & `IBM Plex Mono`)
- **Performance**: 96+ Google Lighthouse score across all categories (FCP < 0.9s, Zero CLS)
- **Deployment**: Cloudflare Workers / Pages static edge

## Local Development

```bash
# Serve locally
npx serve .
# Or via Wrangler
npm run dev
```

## Deployment

```bash
# Deploy to Cloudflare Workers / Pages
npm run deploy
```
